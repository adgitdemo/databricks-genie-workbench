# Genie Workbench Documentation Site

Docusaurus 3 site for the Genie Workbench docs, styled with Databricks branding
(Tailwind + DM Sans/Mono, dark-default). Deployed to GitHub Pages by
`.github/workflows/docs.yml` on push to `main`.

## Local development

```bash
cd docs/site
npm install      # first time
npm start        # dev server at http://localhost:3000/databricks-genie-workbench/
npm run build    # production build into ./build
npm run serve    # serve the production build locally
```

## Structure

- `docs/` — content, grouped into `getting-started/`, `features/`, `platform/`,
  `reference/`. The sidebar is autogenerated from this folder tree
  (`_category_.json` sets each category label and order).
- `src/pages/index.tsx` — custom landing page (hero + capability/persona cards).
- `src/components/` — shared React components (e.g. `Button`).
- `src/css/custom.css` — Databricks color tokens and font overrides.
- `docusaurus.config.ts` — site config, navbar, plugins (Mermaid, search, image zoom).

Source markdown is ported from the repo's top-level `docs/*.md`. See
`docs/site/docs/` for the site copy.
